Scope & method

  • v1 built 10/13/2026. Included: cardiac ablation catheters with a US FDA PMA (or PMA supplement) found in the FDA PMA database, cross-checked against FDA SSEDs/approval orders, FDA-posted IFUs, manufacturer spec sheets/product pages and press releases. Each device row lists source IDs (Sources sheet) for specs, regulatory status and recalls.
  • Recalls: FDA recall database (cfRES) queried by PMA number for every row on 10/13/2026. 'None found' means no record returned for that PMA; it does not rule out field actions filed under another PMA or not yet posted. Some catheters' recalls are filed under a sibling PMA (e.g., TactiFlex SE recall under P130026).
  • Approval date = FDA decision date for the original PMA or the supplement that added that catheter/indication; later indication expansions listed separately. Dates as shown in FDA database (no time zone).

Convention

  • Blank or '[GAP]' (yellow) = not found in an authoritative source reviewed; no value was inferred. '[Verify]' = value derived from source wording that should be confirmed against the IFU.

Discrepancy

  • FARAPOINT electrode count: BSC US spec page = 4 electrodes (2.5 mm tip); FDA SSED P230030/S012 device description says 'five splines with four electrodes, twenty electrodes total' (appears to be carried over from FARAWAVE text). Spec page value used; confirm with IFU.
  • Sphere-9 tip: SSED 'expands to 9 mm'; spec sheet 9.3 mm. Both shown.

Gap

  • Usable length not verified for: DE STSF, STSF, QDOT MICRO, Volt, TactiFlex Duo, HeartLight X3 (Freezor MAX: 90 cm shaft length per S79); StablePoint length only from EU spec sheet (110 cm). Fill from US IFUs (manuals.eifu.abbott, jnjmedtech IFU portal, ifu-bsci.com, Medtronic manuals).
  • TactiFlex Duo (approved 09/04/2026): French size, electrode count/spacing and named generators not on Abbott US page; FDA SSED for P220013/S028 not yet retrievable at the expected URL. Volt dimensions taken from the 2024 CE feasibility paper (investigational device).
  • Not yet added (candidates for v2): ThermoCool SmartTouch (non-SF), ThermoCool SF/NaviStar ThermoCool (P030031 family), IntellaNav MiFi OI / IntellaNav OI (P150005 family), FlexAbility/other Abbott irrigated non-CF catheters, Medtronic Freezor/Freezor Xtra (AVNRT), non-AF ablation catheters (VT/SVT-only 4/8 mm tips), and any other PFA systems from smaller vendors (none others found in FDA product code QZI as of 10/13/2026 besides those listed).
  • Mapping system compatibility for PulseSelect, FARAWAVE (non-NAV), Arctic Front Advance Pro and POLARx is not stated in the reviewed labeling; cells flagged rather than assumed.
